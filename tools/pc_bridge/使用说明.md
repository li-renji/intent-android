# 电脑文件桥使用说明（手机 ⇄ 电脑 无线互传）

## 这是什么

手机不插数据线，连同一个 WiFi，就能在起点OS mini 里：
- 📂 浏览电脑所有盘符和目录
- 📄 打开电脑上的代码/文本文件直接编辑
- 💾 修改后一键保存回电脑（立即生效）
- 📁 在电脑上新建文件夹
- ⬇ 下载电脑上的二进制文件到手机

## 使用步骤

### 电脑端（每次要用时）

1. 双击运行 `D:\INTENT\tools\pc_bridge\启动文件桥.bat`
2. 窗口会显示：
   - **本机 IP**（如 `http://192.168.3.13:8899`）
   - **连接码**（32 位字符串，存在 `pc_bridge.token` 文件里，不会变）
3. 保持窗口开着（关掉即停止服务）

### 手机端（首次配置一次）

1. 打开起点OS mini → 头像菜单 → **设置** → **💻 电脑连接**
2. 填入电脑窗口里显示的 **IP**（如 `192.168.3.13`）和**连接码**
3. 点「连接」→ 自动进入文件浏览器
4. 配置会记住，以后打开直接就是文件列表

## 常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 连接失败 | ① 两台设备不在同一个 WiFi；② 电脑 IP 变了（重启路由器/换网后 DHCP 会重新分配，看电脑窗口里显示的最新 IP）；③ 连接码填错 |
| 能连接但列表报错 | 电脑防火墙拦了——首次运行 node 时弹的"Windows 安全中心警报"要点**允许**；或手动放行 TCP 8899 端口 |
| 文件打不开 | 二进制文件（图片/压缩包）走「下载到手机」；超过 8MB 的文本也会提示改用下载 |
| 手机改了没生效 | 电脑上打开着的编辑器要自己刷新（桥是直接写磁盘，不会通知已打开的程序） |

## 安全说明

- 所有请求都要带**连接码**，不知道连接码的设备无法访问你的电脑
- 服务只监听局域网，互联网上访问不到
- 用完建议关掉桥服务窗口（尤其在不信任的 WiFi 下）
- 想限制访问范围：用命令行 `node pc_bridge.js --root D:\某个目录` 启动，手机就只能看到这个目录

## 技术细节

- 端口：8899（TCP）
- 协议：HTTP + JSON，手机 WebView 直接 fetch（App 已允许明文局域网请求）
- 接口：`/api/ping` `/api/list` `/api/read` `/api/write` `/api/mkdir` `/api/delete` `/api/download` `/api/upload`
- 连接码存放：`tools/pc_bridge/pc_bridge.token`（删除此文件重启服务会生成新码）
